Macros

    Connect the device to see its macros.

    No macros on the device yet. Create one.

    Pick a macro from the list, or start a new one.

    Reference

    One command per line. Commands are case-insensitive. Lines starting with #, // or REM are comments.

    Examples

    Timing

    DELAY 500
    Wait. Milliseconds by default; 250ms and 1.5s also work. Aliases SLEEP, WAIT.
    DEFAULT_DELAY 100
    Delay added after every command.
    TYPE_DELAY 20
    Delay between typed characters for later STRING lines. Default 0.

    Typing

    STRING hello world
    Type the rest of the line exactly. Alias TYPE.
    STRINGLN hello world
    Type the text, then press Enter. Alias TYPELN.

    Keys

    KEY ctrl+c
    Press and release a combo. Join keys with + or spaces: KEY gui r, KEY alt+f4, KEY f5. Aliases TAP, PRESS.
    ENTER
    A line that is just a combo also works, like CTRL+SHIFT+T.
    HOLD shift
    Press and keep held.
    RELEASE shift
    Release those keys. RELEASE alone releases everything. Everything is released when the macro ends or stops.

    Loops

    LOOP 5 … END
    Repeat the block 5 times. Loops nest. LOOP 0 skips the block.
    LOOP forever
    Repeat until B or Stop. Same as LOOP with no number. Aliases REPEAT, ENDLOOP, DONE.

    Mouse

    CLICK right
    Click left (default), right or middle.
    MOUSE_PRESS left
    Hold a mouse button. MOUSE_RELEASE left lets it go.
    MOUSE 10 -5
    Move the pointer relative to where it is, in pixels.
    SCROLL -3
    Wheel. Negative scrolls down.

    Media

    MEDIA playpause
    play, pause, playpause, next, prev, stop, mute, volup, voldown, brightnessup, brightnessdown, eject, calculator, email, browser, home, back, forward, refresh, search, sleep.

    Key names

    ctrl shift alt gui (also win, cmd, meta, super) rctrl rshift ralt rgui altgr enter esc tab space backspace delete insert home end pageup pagedown up down left right f1 to f24 capslock printscreen scrolllock pause numlock menu kp0 to kp9 kpenter kpplus kpminus kpasterisk kpslash kpdot minus equal lbracket rbracket backslash semicolon quote grave comma period slash, any single letter or digit, or one of - = [ ] \ ; ' ` , . /

    Shifted symbols work too and send Shift for you, by name or as the character itself: tilde ~ exclaim ! at @ hash # dollar $ percent % caret ^ ampersand & asterisk * lparen ( rparen ) underscore _ plus + lbrace { rbrace } pipe | colon : doublequote " lt < gt > question ?

    A single character such as ~ or ! works directly in KEY and in bindings. The one exception is +, which joins keys in a combo, so write plus.
